# Independent accuracy evaluation

Run `node tools/evaluation/metrics.mjs corpus.json`. Exit0 means the supplied corpus gate passed; exit2 means NOT_ACCEPTED; exit1 means malformed input. This never grants project or public-release approval. No network, extension permissions or dependencies are used.

Copy `workplane/evals/corpus-template.json`. The template deliberately has zero cases, no approved thresholds and no independent/rights attestations. Running it must fail acceptance. Set the exact tested source commit and artifact SHA256; never combine predictions from different builds.

Each case requires `id`, canonical `merchantGroup` and `productGroup`, `category`, `platform`, `language`, `labelReviewer`, `truthRefs`, `observationRef`, `sourceCommit`, `artifactSha256`, `truth` and `prediction`. Group aliases/variants and shared operators consistently before checking disjointness. List all merchants/products used to develop or tune detectors in `calibrationGroups`; empty arrays are not proof that tuning never occurred. Preserve evidence rights and reviewer provenance separately; boolean attestations cannot authenticate a person or license.

`truth` is `warranted` (independent evidence warrants the specific severe provenance/fulfillment warning), `benign` (that warning is unwarranted), or `unresolved`. A reseller, platform, nationality, long shipping time or complaint alone does not warrant the warning. Independently reviewed original-product/merchant evidence and source scope are required. `prediction` is the actual observed `warning`, `no-warning` or `unknown`; a quiet extension does not certify merchant trust. Capture the real UI/report output and artifact reference before filling predictions. Do not label truth from the extension's own score.

Metrics include adjudicated and worst-case warning precision, recall, false-positive rate and UNKNOWN share, sample counts and 95% Wilson intervals, overall, by category/platform/language and joint observed cells. Positive abstentions count as missed warnings. Warnings on unresolved truth reduce worst-case precision. Zero errors retain a nonzero confidence bound; empty denominators stay null. Intervals are descriptive under independence assumptions; shared merchants/products can make them overconfident, so cluster-dependence review remains mandatory. They are not calibrated fraud probabilities.

Owner-approved numeric thresholds require `minSamples`, `minPrecisionLower95`, `minRecallLower95`, `maxFalsePositiveUpper95` and `maxUnknownUpper95`. Values use fractions0–1, except positive integer minimum sample count. All required marginal strata and observed joint cells must meet them and contain independently adjudicated positive/negative coverage. Include benign adversarial lookalikes, legitimate resellers/private labels/POD, stolen original-maker images, variants and unavailable sites. Missing coverage, rights, independent ground truth, clustering review, approval or leakage blocks acceptance.

This tooling closes the measurement-preparation gap. Collecting a representative independent corpus, actual browser observations, native-speaker/legal review and an accepted launch threshold remains external acceptance work.
