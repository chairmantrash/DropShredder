For a first install, extract the ZIP, open chrome://extensions, enable Developer mode, choose Load unpacked and select the folder containing manifest.json. To update beta1, replace the contents of its existing unpacked folder with these extracted files and click Reload at chrome://extensions. This retains the existing extension identity and local preferences.

Use normal public product pages and open the DropShredder side panel. Grant optional permissions only for the functions you choose. Avoid checkout, payment, accounts and private order-history pages. Removing the extension ends participation; no telemetry enrollment or account is required.

Report problems at https://github.com/chairmantrash/DropShredder/issues with browser/OS, scrubbed public product URL, expected versus actual result and a screenshot free of private information. False accusations, wrong-product attribution, privacy failures and serious slowdown are high-priority stop failures.
