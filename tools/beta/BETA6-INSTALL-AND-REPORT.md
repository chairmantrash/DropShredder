# DropShredder beta 6

Beta6 repairs identity lost from connected ProductGroups, resolves unique local Brand references, reads typed identifiers from current public Product Microdata, and recognizes a sole explicitly selected variant Offer. It preserves ambiguous-variant abstention and excludes private, hidden and related-product regions. Repeated static low-stock wording no longer becomes a countdown-reset warning: actual timestamps and explicit clock durations must show a repeatedly later deadline, and the present/history finding counts as one observation.

Optional outside results appear inside the panel with provider names, dates and scope. Published ScamFerret research outputs are historical opinions; archived urlscan findings concern security. These explicit checks do not change local product scores or submit sites/images for scanning. New reputation navigation is limited to Trustpilot, BBB and government originals.

Public scans retain more labeled brands, manufacturer codes and store identity, with safer bounded policy extraction, supplemental commerce wording, seller-evidence summaries and non-adverse supplier/factory dispatch disclosures. The reviewed brand-domain directory is partial: an official-store verification notice does not prove fraud or counterfeits.

For an existing unpacked installation, disable the extension, back up its folder, replace that folder’s contents with the freshly extracted files, then reload and re-enable the existing extension. Keeping the same folder path preserves its extension ID and local data. For a new installation, extract the ZIP into an empty folder. In Chrome 133 or later, open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select the extracted folder. Open a public product page and then DropShredder's side panel. Grant website access only through the displayed Chrome controls. Open **Outside reports and consumer records** to choose a provider check. No account or paid key is required for the local scan; external public services can be unavailable or rate limited. An absent or favorable outside result does not establish merchant delivery, product safety or legitimacy.

Use Scan, policy, shipping, local history, source comparisons, recall candidates and other available controls on public pages. Never enter credentials or payment details for a test. Stop on private-data exposure, wrong-page attribution, an unsupported severe warning or unsolicited actions. Report the exact public URL, time, language, action, expected behavior, actual behavior and screenshot or deliberately redacted exported report through [the existing repository issue channel](https://github.com/chairmantrash/DropShredder/issues). Do not include personal/account/payment data or full browsing history.
