# ADR 20261006-001 — Zero-backend core

Status: Accepted

DropShredder core functionality must not require a hosted backend, paid API, subscription, cloud database, or shared secret.

Rationale:
- owner has no infrastructure budget;
- local-first architecture improves privacy;
- avoids service shutdown/API pricing risk;
- makes public contribution/testing easier.

Optional user-supplied integrations may exist later, but failure/absence may not disable core detection.
