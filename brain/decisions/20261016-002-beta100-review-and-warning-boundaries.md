# DS-060 — Scoped visible reviews and truthful warning boundaries

Decision: retain one self-contained serialized extractor and its existing <=9000 element traversal, extending only current-product Judge.me review collection. Chrome serializes the function body, so importing page-world helpers would create broken closure references. A second full DOM traversal/injection for reviews would add page work and transaction races. Do not introduce eval, source-string assembly, shared page globals or a blanket source-size exemption.

The extractor grows from the DS-059 <=45000-byte allowance to a narrow <=49000-byte allowance conditional on this decision and the previous serialized-function review. Its current source remains below49000 bytes. Preserve all existing output/work caps (60 reviews, 160 text nodes per review field, 4000 body characters, <=32 newly visited ancestors). A per-scan WeakMap caches validated visibility without retaining DOM or data after the synchronous scan. False subtree results do not mark public ancestors false. Recognized widget, same-origin product URL, explicit variant compatibility, hidden/private exclusions and stable review-ID deduplication are mandatory. Platform presence carries no adverse weight. No new network, permission, provider, dependency, background loop or pagination.

A merchant's verification attribute is an attributed widget state, never independent purchase verification. Missing/unknown states remain undefined. Product-wide reviews do not establish variant-specific quality. Text duplicates are retained across different review IDs for the existing detector, but duplicate rendering of the same ID cannot inflate counts. Hidden legacy/SSR copies, store-wide widgets and other-product reviews are excluded. Current newer widget shapes without supported public DOM remain unresolved.

A warning stamp counts only independent non-info evidence with finite positive effective weight, using the same engine validation as scores. Informational notes must show NO VERDICT with neutral styling in every tone. No evidence thresholds, country/platform weights or severe gates change.

Shipping observations require explicit shipment wording; generic from/to prose and temporal promotions are insufficient. Origin ends before the destination. Comparison requires one recognizable jurisdiction on each side; unknown or multi-country text abstains. Original two real false positives and positive tracking controls are mandatory regressions. Negation and quote controls were additionally reproduced before correction.

This bounded source-size exception is an architecture choice for serialized injection, not an accuracy approval. Native/100-site verification and full regressions remain required. Independent market accuracy and customer satisfaction cannot be inferred from fixtures or coverage counts.
