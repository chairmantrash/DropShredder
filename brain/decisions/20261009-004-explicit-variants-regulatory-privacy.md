# Explicit variants, official-notice scope and safe image hunts
Date: 2026-10-09. Scope DS-035, internal PR #9.

1. Page-context data authority: accept only unique ProductGroup variants selected through `main` controls with explicit bounded attribute names (color/colour/size/capacity/material). This covers named options, checked radio, and explicit pressed/checked data-option swatches. Absent, conflicting, disabled or unlabelled controls cannot select an item. The same controls enter the snapshot's page-selection stamp, invalidating stale reports/exports on change. A named option never overrides a different exact URL target. No access to private page JS or arbitrary input values.
2. Recall match precision: exact brand/model and checked GTIN retrieval remain first; lot/serial conditions are exact or fixed-width range rules. An unknown required number and official serial validation both result in **unresolved**; out-of-scope observations are **excluded**. No web-visited consumer serial is scraped, no score increases, and an unmatched notice is not a safety clearance.
3. Automatic top-right warning: qualifying product detail + granted permission + local passive evidence remains the gate. Do not suppress evidence-backed warning just because a severe gate can be satisfied; headings and evidence text remain cautious, with a manual full scan for attribution. No silent external requests.
4. Reverse-image searches: external Lens/TinEye URLs can disclose the source image URL. Never forward an image URL with query/fragment (possibly signed access tokens), embedded credentials, private/invalid origin, or HTTP scheme. Fall back to the provider's manual search page. The user must explicitly select which external destination to open.

Neither OCR/embeddings nor silent remote intelligence updates are approved by this change. The free/local-first, minimal-permissions contract remains in force. Evidence: relevant source and bounded fixtures; exact packaged Chromium validation and representative storefront/category evaluations are separate gates.
