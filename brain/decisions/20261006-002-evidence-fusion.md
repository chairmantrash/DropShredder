# ADR 20261006-002 — Evidence fusion over binary classifier

Status: Accepted

Do not implement a single opaque "AI scam detector."

Verdicts combine typed evidence families, contradictions, chronology, and independence gates. Strong UI language is allowed only when evidence quality satisfies the authority policy.

Why:
- dropshipping is not itself identical to fraud;
- legitimate makers can have images stolen by mass-market sellers;
- generic traits create unacceptable false positives;
- explainable evidence is more defensible and useful.
