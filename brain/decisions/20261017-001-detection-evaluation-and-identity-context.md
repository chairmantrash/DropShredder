# DS-061: measure detection honestly and separate affiliation from adverse evidence

Date: 2026-10-17. Owner directive permits replacement of every detection component and requests 59% detection.

Detection acceptance now means recall on independently reviewed positive cases, reported with precision, false-positive rate, abstention, availability and uncertainty. The provisional engineering gate is observed recall >=59%, precision >=95%, FPR <=5%, with >=50 independent positive and >=50 negative merchant groups in a merchant/product-lineage-disjoint holdout. It is a sample acceptance criterion, not a customer satisfaction guarantee. Unknown labels, historical source-list membership, successful DOM extraction and developer fixtures cannot certify this gate. A checker verifies manifest declarations and arithmetic; it cannot itself authenticate external evidence. Independent adjudication remains necessary. No current dataset passes.

The runtime currently weights affiliated sister stores as strong identity evidence and transparent corporate groups as moderate. Because the canonical engine converts identity weights into merchant-risk warnings, this contradicts the same rule's statement that affiliation alone is not fraud. All packaged affiliation and plain cross-domain references now remain visible with zero adverse weight. Domain-specific, scoped complaint/enforcement evidence must supply any actual adverse finding. This supersedes the old tests expecting strong/moderate affiliation severity; it preserves the identity result and the severe provenance/fulfillment gate. Future-dated network reviews are not fresh. Hostname substring lookalikes do not establish a cross-domain reference.

Replace the dispatch parser's broad phrase ordering with bounded clause matching: supplier/manufacturer subjects and vendor origins are recognized; negation, questions, quotations, definitions, future intentions and deliveries into retailer warehouses abstain. Supplier-direct disclosure remains a merchant claim with zero adverse weight, not a calibrated dropshipping probability. A 12-source search-selected statement challenge is a parser diagnostic, never independent fraud accuracy.

Review bodies must not become merchant-authored page claims. Apply the existing bounded visibility/private-subtree reader to Amazon-shaped review fields as well as Judge.me. A missing verification badge stays unknown. Review extraction count is not fake-review detection. The serialized scanner shrinks from48,190 to48,145 bytes; no cap or privacy/work budget increases.

No new network provider, permission, runtime dependency, paid service or backend. No main/Store merge or public release. Preserve baseline failures, mismatched capture hashes, native environment failures and partial/unsupported coverage. Restore a real candidate acquisition path and independent labels before tuning score weights or making a 59% claim.
