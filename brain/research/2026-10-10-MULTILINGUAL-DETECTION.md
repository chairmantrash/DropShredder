# Merchant-language detection research (DS-040)
Retrieved: 2026-10-10. Owner: /root. Implementation baseline fe0b2db.

Interface language and merchant language are independent. An English Chrome profile must detect a Bengali product page and an Arabic profile must detect English pages. Never use UI locale to determine the page's evidence language or geography.

Primary findings, catalogued before implementation:

* Schema.org price (https://schema.org/price): structured machine prices use ASCII digits and a dot decimal separator, with explicit priceCurrency rather than ambiguous currency symbols. Preserve strict JSON-LD parsing; parse localized visible prices separately using declared page language/explicit currency, reject ambiguity and ranges. Product/Offer field names are vocabulary identifiers, not translated display labels.
* Chrome scripting (https://developer.chrome.com/docs/extensions/reference/api/scripting): injected function bodies cannot rely on surrounding closures; pass the finite offline kit as serializable data to the existing isolated scanner and selection-stamp transactions. Do not load a translator, inject into the merchant's main world or broaden permissions.
* W3C String Searching, Group Note Draft 2026-09-30 (https://www.w3.org/TR/string-search/): human-language matching requires different treatment from identifier equality. Whitespace-only/ASCII-only segmentation erases non-Latin evidence. Keep original source text separately from normalized matching text; do not claim translated wording is a merchant quotation.
* Unicode UTS18 (https://unicode.org/reports/tr18/): ASCII word boundaries are insufficient for script-aware matching. Use letter/mark/number boundaries for vocabulary phrases; retain Indic combining marks and joiners. CJK matching cannot assume spaces.
* ECMA402 Intl.Segmenter (https://tc39.es/ecma402/#sec-intl.segmenter): native word segmentation is available without a runtime model or network service. Apply bounded segmentation to original-language review/title similarity. This is lexical retrieval within a language, not semantic cross-language translation or proof of common supplier identity.

Plan: reviewed agent-authored phrase kits for seven languages plus English, original-span mapping for quoted observations, localized purchase/navigation/privacy/variants/digits/currency and scoped commerce/rule vocabulary. Regression fixtures must compare evidence IDs, weights, severe gates, exact product attribution and preserved quotations, including negated claims and misleading grids/editorial/sensitive surfaces. Phrase dictionaries are bounded support, not universal linguistic comprehension. Independent native-language review and representative live-site calibration remain distinct gates.
