# Memory model

## Working memory
Active task, relevant files, current hypotheses, current test results, blockers. Disposable after task completion.

## Episodic memory
Per-task/run records: what was attempted, evidence observed, failures, fixes, handoff state.

## Semantic memory
Stable product truths: architecture, evidence taxonomy, privacy/performance constraints, marketplace semantics, scoring doctrine.

## Procedural memory
Repeatable methods: adapter workflow, evidence-rule promotion, release verification, regression triage.

Agents should consolidate durable knowledge from episodic records into semantic/procedural docs when it will matter again.
