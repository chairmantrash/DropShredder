# ScamFerret: what it detected and useful DropShredder reuse

Investigated October13,2026. Verdict: use the published project as a source of dated investigation leads and reproducible comparison material. Its additional capability is gathering external evidence and reasoning about merchant/brand claims. Its historical classifications are not current truth or calibrated dropshipping probabilities. No public managed detection API was found in the published artifact. DropShredder's core remains local-first and $0; this task makes no paid model calls, adds no cloud dependency, and imports no blacklist into runtime.

## Primary sources and historical method

The [February14,2025 paper](https://arxiv.org/html/2502.10110v1) describes an LLM agent selecting webpage/text/link, web-search, Reddit/X, WHOIS, DNS and TLS tools. It iterates evidence collection and produces a binary classification with reasons, without fine-tuning. Its April2024 experiment used2,400 balanced scam/legitimate sites, filtered for accessibility and manually reviewed by three security engineers. Reported GPT-4 accuracy was97.2% across four English scam types and99.3% for shopping across English/German/Japanese. Mean original cost was about$0.207/URL and73seconds. Those figures describe that historical benchmark, not current service pricing or DropShredder accuracy. The paper reports false positives involving ordinary free shipping, negative reviews and WHOIS privacy, and failures involving missing information. Domain turnover and correlated examples further limit transfer to current pages. The useful methodological lesson is to collect corroborating external evidence; binary output alone does not establish an independently accepted accusation.

The [authors' artifact](https://github.com/ScamFerret/artifact) is pinned here to [8cf8dc631edafe584141e2f95f0c0f51855fb7bc](https://github.com/ScamFerret/artifact/tree/8cf8dc631edafe584141e2f95f0c0f51855fb7bc), September30,2025. Its later GPT-4.1 shopping results are distinct from the original paper experiment. Source paths, hashes, retrieval time and original result records are preserved in [the source receipt](../runs/DS-055-SCAMFERRET-SOURCE-RECEIPT-20261013.json); discovery metadata is in [the source index](DS-055-SCAMFERRET-SOURCES.json).

## How its explanations differ from our scans

The pinned expanded results contain54 relevant files across49 current candidate hostnames. Fifty contain valid machine-readable scam classifications, one contains a non-scam classification, and three have textual scam conclusions but invalid JSON. Only two result URLs match an audited resource path/query; the remaining matches are merchant-host context. These are August30–September1,2025 model conclusions. They do not authenticate current operators, products, complaints or delivery outcomes.

| Audited host | Published model explanation, paraphrased | What DropShredder can responsibly reuse |
|---|---|---|
| yeezys.com.mx | Claimed unusually cheap branded goods, official-product claims, insufficient company identification and external non-delivery complaints. The exact audited Yeezy350 URL has a published result. | Investigate the specific official/authorization claim and retrieve dated complaint sources with exact merchant identity. Cheap prices alone do not establish fraud. |
| pokemoncenter.co.at | Claimed brand impersonation, company/domain mismatch and private WHOIS. | Verify the asserted brand relationship against an official source. Discard WHOIS privacy and country/TLD as standalone adverse evidence. |
| tuketa1.com | Cited review/social complaints, urgency, endorsements and health claims; WHOIS lookup failed. | Preserve exact claim text and seek original complaint/endorsement records. An unavailable lookup is unknown. |
| jordans.com.mx | Cited originality claims, low prices and incomplete operator information, alongside registrant geography. | Check originality/authorization and identifiable operator evidence. Geography contributes no adverse weight. |
| vionic.es | Cited brand mimicry and authorization uncertainty, plus opaque WHOIS/certificate observations. | Check actual official affiliation; uncertainty or ordinary certificate details are not proof. |
| beringhorloges.com | The model abstained from a scam classification despite the file's source-positive directory. | Preserve disagreement. Neither directory placement nor the model's answer establishes current legitimacy. |

The receipt links each row to its original published JSON. Reasons are model assertions; several refer to scam-checking/review sources without complete linked tool observations in that result file. This task did not independently verify those assertions. The [offline comparison tool](../../tools/evaluation/scamferret-compare.py) records source dates, strict output validity, host-versus-resource matches and current case statuses. It makes no model/network calls and never turns labels into expected runtime answers. The original pre-repair comparison remains [here](../runs/DS-055-SCAMFERRET-COMPARISON-20261013.json); the [repaired-run comparison](../runs/DS-055-SCAMFERRET-REPAIRED-COMPARISON-20261013.json) is separate.

For the same Yeezy page, our previous native scan was refused because a dormant password field triggered the privacy guard. Fixing that defect permits public extraction. It does not automatically supply ScamFerret's external complaints, prove official-brand impersonation, or make numerical resale/dropshipping estimates valid. Extraction coverage and fraud-detection accuracy are different outcomes.

## API and deployment findings

The [README](https://github.com/ScamFerret/artifact/blob/8cf8dc631edafe584141e2f95f0c0f51855fb7bc/README.md) documents a containerized batch process with target-file and output directories. It configures Azure or Databricks model credentials and external-tool credentials; LangSmith tracing is enabled in its example configuration. Its GPL-3.0 license is preserved with our source inventory. That license does not grant independent rights to third-party webpage content, photographs, reviews or brands. No separately advertised supported public detection endpoint, client SDK, API authentication/rate limits or service SLA was found in the authors' published material. A similarly named domain is not evidence of author affiliation.

The [application](https://github.com/ScamFerret/artifact/blob/8cf8dc631edafe584141e2f95f0c0f51855fb7bc/system/app.py) reads a target file and runs a thread pool; it has no published HTTP server/router. It uses cloud chat models, Tavily, PRAW/X, WHOIS/RDAP, dig and certificate-transparency queries. The executor permits15iterations, while the [prompt](https://github.com/ScamFerret/artifact/blob/8cf8dc631edafe584141e2f95f0c0f51855fb7bc/prompt/prompt_template.txt) asks for at most10actions and hardcodes2025 as the current year. The [container configuration](https://github.com/ScamFerret/artifact/blob/8cf8dc631edafe584141e2f95f0c0f51855fb7bc/system/docker-compose.yml) exposes no detection port. This supports the bounded finding above; it cannot exclude an unpublished/private API.

These Python, shell, browser and cloud-model components cannot be dropped directly into the MV3 extension. Calling third-party APIs internally is not the same as providing an API consumers can call. Open model evaluation results also do not provide a free lightweight browser model: the published implementation still needs serving infrastructure and suitable compute.

## Concrete integration judgment

1. **Useful now, implemented:** preserve pinned results and add the offline historical comparison tool. Use evidence-linked leads to select future cases and investigation questions, with source age and entity uncertainty visible. Keep development-exposed cases separate from independent acceptance.
2. **Useful next within existing local design:** improve evidence provenance for official-brand claims and operator relationships. Combine merchant-authored statements with dated official directories, actual review/complaint URLs and entity matching. Existing RDAP, review-search, policy/shipping and source-hunt functions already cover parts of this workflow; add evidence quality rather than another generic scam score.
3. **Optional future cloud investigation:** an owner-operated wrapper could accept a public URL and return validated evidence records. It would be a new service we operate, not an existing ScamFerret API. It requires provider credentials, costs, explicit data disclosure and separate testing. Public-only fetch boundaries, untrusted-page handling, disabled remote tracing, current dates and observed budgets follow from this architecture. Model conclusions should remain suggestions until evidence is checked; correlated source copies count as one origin.
4. **Do not integrate:** historical positive lists as automatic accusations; model percentages as our accuracy; geography, privacy registration, platform or ordinary resale as fraud indicators; unpaid presumed service access; automatically accepted output from the three malformed JSON files.

The runtime repair addresses observed public-page coverage. Independent merchant/product-disjoint, rights-cleared current labels and owner-approved accuracy thresholds remain open release-promotion work. Experimental beta is already authorized and does not await an invented new entry gate.
