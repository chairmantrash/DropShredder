## Delivered implementation
1. Optional weekly intelligence subscriptions: alarm-triggered signed feed refresh with exact user-pinned publisher Ed25519 key, HTTPS host grant pre-existing, seven-day throttle, higher version only, single serialized list writer, rollback and user deletion. Never auto-scrape random merchants or refresh untrusted unsigned feeds.
2. Storefront product search badges: Amazon, Etsy, Walmart, visible neutral original-product links limited to genuine result pages with existing auto-protection opt-in, no automatic remote investigation.
3. Deeper product tracing: exact imported manufacturer/importer/seller record-role leads, GTIN/brand-model and variant exclusions, local historical product cross-domain graph, vetted indexed supplier source launchers; no unsourced factory accusations.
4. Local product similarity: lightweight 192d deterministic subword hashing and conservative lexical overlap. This intentionally avoids heavyweight neural embeddings and cloud inference; report as a local retrieval candidate not an authenticity score.
5. Offline packaging label reader: product PNG/JPEG/WebP selected by user, local BarcodeDetector when available and lazy packaged Tesseract/English WASM fallback, no CDN/model fetch or image upload, checksum validation, manual upstream search launches, memory bounds.
6. Optional BYO-key supplier web search: user opt-in Brave API query with manual Chrome host approval, transient key cleared after click, no Chrome storage/telemetry, bounded ten results, no score change, no mandatory purchase. User must evaluate potential provider plan fees.
7. Existing provider reviews, RDAP/GLEIF/CPSC, signed user intelligence, review provenance, platform fingerprinting, claim and shipping contradictions, guarded toast, local image hashing/reverse-image searches and styled sidebar remain integrated.
