# DS-003 — Structured product extraction
Status: RUNNING
Owner: lead

## Goal
Extract stable commerce facts before using brittle DOM-specific selectors.

## Order
1. JSON-LD / Schema.org Product
2. OpenGraph/meta fallback
3. Marketplace adapter
4. Generic DOM heuristics

## Acceptance
Recover where present: title, description, price/currency, seller, brand, SKU, MPN, GTIN, images, canonical URL, and shipping text.
Malformed JSON-LD must not abort scanning.
