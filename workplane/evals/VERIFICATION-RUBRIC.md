# Verification rubric

For release-blocking or scoring changes verify:
1. Requested behavior exists.
2. Negative/abstention case exists.
3. Evidence is human-readable and traceable.
4. Independence gate cannot be inflated by duplicate symptoms.
5. Privacy and permission scope did not expand silently.
6. Passive-path performance did not gain heavy OCR/ML/network work.
7. Adjacent marketplace/generic extraction still works.
8. Regression fixture added for every discovered bug when feasible.
