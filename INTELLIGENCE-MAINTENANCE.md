# Reference and case maintenance

Owner-authorized weekly research tasks are enabled: litigation Monday mornings and the broader DropShredder intelligence sweep Tuesday mornings, America/Chicago. Reports arrive in ChatGPT. These tasks research and prepare reviewable Git changes; they do not make installed extensions perform background research or automatically distribute a new release.

| Database / evidence | Refresh focus | Runtime evidence window / boundary |
|---|---|---|
| Court dockets and litigation | Exact legal party, original docket, current disposition, appeal/vacatur/dismissal, relevant category | Seven days; stale records excluded; discovery aggregators link-only |
| BBB and consumer-bureau standing | Letter grade vs accreditation/reviews, resolution, exact entity and changed status | Most accepted conduct records thirty days; missing/NR/non-accredited neutral; PROFECO link-only |
| FTC / Competition Bureau enforcement | Warning/complaint/proposed order/final outcome and subsequent corrections | Thirty days; current source inspection does not turn an allegation into a finding |
| CBP / OFAC restrictions | Scope, active/modified/revoked/superseded status | Seven days; exact subject; replicated feeds share publisher lineage |
| GLEIF / company registries | Exact entity identifiers and current legal status, registry jurisdiction | Ninety days; active identity is not trust or product approval |
| Trade / USMCA / CROSS | Exact goods, origin rules, dated ruling or certification scope | Source-specific metadata, generally thirty days; no company-wide or wholly-regional badge |
| CPSC / Health Canada recalls | Manufacturer, model/variant, remedy and notice updates | Exact product scope; source references or candidate notices are not blanket retailer guilt |
| Product / supply-chain certification | Certificate/assessment scope, issuer, site/product, expiry and access terms | Source-specific recheck plus original validity; assessments never substitute for overall standing |
| Carrier / FMCSA SAFER | USDOT/MC/MX identity, current rating/authority/insurance context and source freshness | Link-only; registered-carrier coverage; no litigation or delivery-performance inference |
| Regional outlets / manufacturers / providers | Current disclosed operator, sourcing vs manufacture, sale and actual dispatch | Dated reference map; exact eight-stage origin dossier separately requires fresh complete evidence |
| Platforms / merchant networks / sourcing and review tools | Current capabilities, observable features, ownership changes, restricted access and obsolete heuristics | Country/platform/tool presence neutral; dated domain-specific allegations never inherited |
| Papers / competitors / API references | Current versions, shutdowns, quotas, terms and reproducibility | Documentation/research presence is not runtime acceptance or inherited accuracy |

Use `workplane/CURRENT-STATE.md`, `workplane/WORK-QUEUE.md` and the active task packet before edits. Source directories: `intelligence/standing-sources-20261010.json`, `intelligence/north-america-commerce-20261010.json`; prior-topic inventory and source-presence ledgers live alongside them. DS-042/043 reports document source access failures and manual-only integrations.

For each refresh, record the exact visited source and observation date, original event date, scope, publisher family, retrieval/access status, changes and correction history. Do not advance dates on unvisited entries because a homepage was checked. Keep no-hit results and unavailable/partial coverage neutral. Preserve superseded evidence in research history while current assessment uses the latest properly linked record. Resolve equally dated contradictory snapshots explicitly.

New machine signals require public observable evidence, legitimate counterexamples, meaningful regression checks and current release authority. Preserve source licenses/access limits and current local-first privacy/security/performance gates. Do not scrape restricted commercial datasets, buy documents, infer missing identity, import paid score feeds, add a backend/permissions, or treat a signed package as authenticated truth. Check all supported source domains and the existing eight-tab batch bound when query registries change.

Published extension updates, real-time source availability, independent case authenticity, representative seller/category calibration and public release acceptance remain separate gates. The weekly schedules are maintenance commitments, not exhaustive database-coverage guarantees.
